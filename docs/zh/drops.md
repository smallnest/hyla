# 拖放

在 Hyla 里拖动文件、目录和窗格，落在哪里就到哪里。

## 文件拖进窗格

把文件拖到窗格上，Hyla 会把它们的路径按 shell 的写法输入到程序里。拖进来的是目录时，Hyla 会遍历它：所有文件写成一行，最多 2000 个文件、8 层深。

拖到[另一台机器](./remote.md)上的窗格时，文件会先上传，再输入路径，程序拿到的是它所在机器上的路径。

## 窗格拖到窗格上

按住窗格标题栏把它拖到另一个窗格，会先预览它将占的位置：

- 拖到**左、右、上、下**边缘：把那个窗格拆开，并排在旁边；
- 拖到**中间**：两个窗格互换位置。

拖动时预览会在各个区域之间滑动，松手前就能看清它落在哪。

## 目录拖到边栏

把目录拖到边栏，就把它作为一个项目打开。拖多个目录时，每个尚未打开的项目各开一个会话；已经登记的项目沿用原来的。文件、以及 Hyla 读不了的目录会被拒绝。这一步总是在本机打开，即使当前选中的是远程会话。
