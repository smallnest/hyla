# 雨蛙

Hyla 是雨蛙属的名字，其中一只住在你的窗口边上：手搭在标题栏上，眼睛看着你的会话。

## 它会做什么

- **跳一下**：有会话需要你处理时，它先让窗口跳进你眼里，比边栏更早。
- **探头**：智能体在干活时，它从边上探出头看，活儿干完再缩回去。
- **睡着**：一切都安静的时候。
- **回应点击**：戳它一下会有反应，菜单栏那只也一样。

它从不挡住你正在读的东西：它站在窗口的边上，工具栏之上。

## 挪位置，或者换一只

沿着窗口边缘拖动它，放到不碍事的地方：`pet-offset` 记下位置，0 到 1 表示窗口宽度上的位置。

`pet-set` 决定住在那里的是一只什么：`hyla` 是雨蛙，`codex` 是 Codex 应用正在用的宠物，也可以是 `~/.codex/pets` 里某个宠物目录的名字。Codex 宠物的高度由 `pet-size` 决定，是应用里尺寸的 0.5 到 3 倍。

## 关掉

**视图 › Toggle Hyla**（<kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>K</kbd>）可以让它消失或回来，[配置文件](./configuration.md#appearance)里的 `pet = false` 也一样。关掉之后，窗口边缘干干净净，菜单栏图标还在。
