# カエル

Hyla はアマガエルの属の名前で、その一匹がウィンドウの端に住んでいます。手はタイトルバーに、目はセッションに。

## 何をするか

- **跳ねる**: 対応が必要なセッションがあると、サイドバーより先にウィンドウが目に入るように。
- **覗く**: エージェントが働いている間は端からのぞき、終わると戻ります。
- **眠る**: 何も起きていないとき。
- **クリックに応える**: つつくと反応します。メニューバーのカエルも同じです。

読んでいるものを隠すことはありません。ウィンドウの端、ツールバーの上に立っています。

## 動かす、替える

端に沿ってドラッグすれば、邪魔にならない場所へ移せます。`pet-offset` がその位置を 0 から 1 で覚えます。

`pet-set` はそこに住むものを決めます: `hyla` は雨蛙、`codex` は Codex アプリが使っているペット、`~/.codex/pets` の中のペットのディレクトリ名でもかまいません。Codex のペットの高さは `pet-size` で、アプリでの大きさの 0.5 から 3 倍です。

## 消す

**表示 › Toggle Hyla**（<kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>K</kbd>）で消したり戻したりできます。[設定ファイル](./configuration.md#appearance)の `pet = false` も同じです。消すとウィンドウの端は素になり、メニューバーのアイコンは残ります。
