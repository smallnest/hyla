# はじめに

Hyla は macOS、Windows、Linux のための、コーディングエージェントと働くターミナルです。Claude Code、Codex、開発サーバー、テストの監視を、それぞれ自分の**セッション**で動かします。Hyla はセッションをプロジェクトごとにまとめ、動いているもの、対応が必要なもの、終わったものをサイドバーで示します。

## ウインドウより長生きするセッション

セッションはアプリの中ではなく、Hyla が起動する小さなデーモン **hylad** の中で動きます。Hyla を終了しても全部そのまま動き続け、開き直せばセッションもペインもスクロールバックも元の場所にあります。

::: tip
Hyla の終了（<kbd>⌘</kbd> <kbd>Q</kbd>）はセッションを止めません。すべて終えるには **Hyla › 終了してすべてのセッションを終了…**（<kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>Q</kbd>）を使います。
:::

## エージェントのために

- **状態がひと目で。** 各ペインは*作業中*、*待機中*、*アイドル*、*エラー*、*終了*のいずれかです。対応が必要なセッションは目に留まり、<kbd>⌘</kbd> <kbd>J</kbd> ですぐ移動できます。
- **必要なときだけ通知。** よそを見ている間にエージェントが終わった、失敗した、あなたを待っている、そのときに知らせます。
- **エージェントが動かせる CLI。** `hyla` コマンドはセッションを開始し、ペインを分割し、入力し、待ち、画面を読みます。エージェントは自分の隣で仕事を走らせ、進み具合を報告できます。
- **中身は Ghostty。** ターミナルは libghostty が描くので、Ghostty のテーマ、フォント、設定キーが期待どおりに効きます。

## ターミナル以上のもの

- **[ファイル](./files.md)**：サイドパネルでファイルを見て、ペインへドラッグ。ウィンドウを離れません。
- **[ドラッグ＆ドロップ](./drops.md)**：ファイルはペインへ、ペインはペインへ、フォルダはサイドバーへ。
- **[リモートマシン](./remote.md)**：SSH、WSL、Kubernetes Pod、もう一つの Hyla を、手元のセッションと並べて。
- **[Hyla Pocket](./pocket.md)**：同じセッションを Android のスマートフォンで。
- **[外観](./appearance.md)**：半透明、ガラス、画像、セッション切り替えのアニメーション。
- **[カエル](./frog.md)**：ウィンドウの端のあの子。残しておくなら。
