# ファイル

サイドパネルには、セッションが作業しているフォルダの **ファイル** ビューがあります。ウィンドウを離れずにファイルを覗けます。

[![Hyla のウインドウ。右側にファイルパネルが開き、セッションのフォルダを表示している](/img/docs/window-ja.jpg)](/img/docs/window-ja.jpg)

*サイドパネルのファイルビュー。選んでいるセッションのフォルダを表示します。*

## 開く

**表示 › ファイルを切り替え**（<kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>F</kbd>）を選ぶか、サイドパネルのファイルボタンを押します。ツリーは選んでいるセッションに従います: プロジェクトのフォルダ、ホームで始めたセッションならホーム、[別のマシン](./remote.md)ならそのフォルダです。

<a href="/img/docs/panel-ja.jpg"><img src="/img/docs/panel-ja.jpg" width="360" alt="ファイルツリー: フォルダはその場で開き、ファイルは種類のアイコンが付く"></a>

*フォルダはその場で開きます。ファイルは開く前に種類が分かります。*

## 読む

ファイルをクリックするとウィンドウに開きます。テキストはテキストとして、画像は画像として表示され、バイナリファイルはその旨が表示されます。読むだけで何も変更しません。

変更したいときは、ターミナルからエディタを開くか、エージェントに任せ、もう一度開けば新しい内容が見えます。

## プログラムに渡す

ツリーからファイルをペインへドラッグすると、Hyla がそのパスを打ち込みます。このマシンのシェルにはパスが、[別のマシン](./drops.md)のペインには先にアップロードされたファイルが届きます。

## これは何ではないか

エディタでも diff でもありません。[変更](./changes.md)がエージェントの変更をファイルごとに見せます。
