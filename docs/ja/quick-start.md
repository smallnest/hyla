# クイックスタート

Hyla をインストールしてプロジェクトを開き、終了しても動き続けるセッションで最初のエージェントを動かしましょう。

## インストール

[リリースページ](https://github.com/smallnest/hyla/releases)から最新の Hyla をダウンロードします。macOS では **Hyla.app** を“アプリケーション”フォルダにドラッグします。Windows では **Hyla Setup** インストーラを実行します。管理者権限は不要です。

Windows では、セッションは PowerShell 7 がインストールされていればそれで、なければ Windows PowerShell で動きます。`cmd` や Git Bash の `bash` など別のシェルは、**設定 › シェル**で選べます。疑似コンソールを使うため、Hyla には Windows 10 1809 以降が必要です。

### コマンドラインツールのインストール

**Hyla › コマンドラインツールをインストール…** を選ぶと、`hyla` が `PATH` に入ります: macOS では `/usr/local/bin` に、Linux では `~/.local/bin` にリンクが作られ、Windows では Hyla の `bin` フォルダがユーザーの `PATH` に追加されます（それ以降に開いたターミナルで有効）。どのターミナルでも、次のコマンドで確認できます:

```sh
hyla help
```

ターミナルで `hyla` とだけ入力すると、アプリが開きます。

## プロジェクトを開く

<kbd>⌘</kbd> <kbd>O</kbd> を押してフォルダを選びます。Hyla はそれをプロジェクトとしてサイドバーに追加し、そこでセッションを開きます。

コマンドラインから始めることもできます。新しいセッションは、そのディレクトリに合うプロジェクトに入ります:

```sh
cd ~/code/my-app
hyla new --focus
```

## エージェントを始める

ほかのターミナルと同じように、セッションでエージェントを実行します:

```sh
claude
```

あるいは、サイドバーで見分けやすい名前を付けて、専用のセッションを与えます:

```sh
hyla new -n fix-login -- claude
```

エージェントが作業している間、そのセッションは**作業中**と表示されます。何かを尋ねるために止まると**待機中**に変わり、Hyla が通知します。<kbd>⌘</kbd> <kbd>J</kbd> でそこへ移動できます。

## 何も失わずに終了する

<kbd>⌘</kbd> <kbd>Q</kbd> を押します。セッションは hylad の中で動き続けます。もう一度 Hyla を開けば、スクロールバックも含めてすべてそろっています。
