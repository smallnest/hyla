# 同期

Hyla の設定——テーマ、フォント、キー、エージェント、Feishu、Tailcat——はひとつのファイルです。**同期** はそれを、どのマシンからも届くサーバー経由で同じに保ちます: WebDAV フォルダ、S3 互換のバケット、または GitHub のリポジトリです。

スナップショットは書き込んだマシンで暗号化されます。サーバーにあるのは暗号文だけです: 設定は読めませんし、パスフレーズなしにファイルを手に入れても読めません。

## 同期するもの

設定ファイルそのものだけです。`hyla config path` が示すファイルで、既定値と違うところだけを持ちます。同期したマシンは、他のマシンの設定をそのまま使います。

**同期しない** のは、そのマシン自身のものです: セッションとそのターミナル、プロジェクト、サイドバーの SSH と K8s のホスト、ウィンドウの大きさ、最後に選んでいたセッション。

## 置き場所

| サーバー | 入力するもの |
| --- | --- |
| **WebDAV** — 堅果雲、Nextcloud、ownCloud | アドレス（`https://dav.jianguoyun.com/dav/` など）、ユーザー名、アプリパスワード |
| **S3 互換** — MinIO、R2、B2、OSS、COS | エンドポイント、バケット、プレフィックス、リージョン、アクセスキー、シークレットキー |
| **GitHub** | `owner/name`、パス（`hyla/config.enc` など）、ブランチ、トークン——リポジトリは **非公開** に。スナップショットには鍵が入りますが、暗号文としてだけです |

WebDAV のアドレスの下に `hyla/` フォルダを作ります。バケットとリポジトリでは `hyla/config.enc` を使うので、同じサーバーに他のものも置けます。

## パスフレーズ

どのマシンでも同じパスフレーズを入力し、それがスナップショットを封じ、開きます。Argon2id で鍵を導き、AES-256-GCM で暗号化します: パスフレーズが違う、あるいはサーバー上でファイルが変わっていれば、何も開けません。

**忘れないでください。** 取り戻す方法はありません: パスフレーズなしでは、どのマシンでも、Hyla でも、誰も開けません。

パスフレーズとサーバーの資格情報は各マシンに留まります。設定の隣の `sync.json`（自分だけが読める）に置かれ、同期される内容には入りません。スナップショットが自分自身の鍵を運ぶことはありません。

## いつ同期するか

- **起動時**: 取得します。しばらく開いていなかったマシンも、他のマシンの設定で始まります。
- **変更後**: 設定を変えると 30 秒後に送ります。続けて変えた分は一度にまとまります。**自動で同期** を切れば、指示したときだけ同期します。
- **指示したとき**: **設定 › 同期 › 今すぐ同期**、または `hyla sync`。

設定ファイルのないマシンは、空のものを送らずサーバーのものを取ります。

## 両側が変わったとき

同じ設定を同時に変えることはよくありませんが、起こります。そのとき **このマシンの設定が残ります**: サーバーのものは `config.remote-<マシン名>-<時刻>` として隣に保存され、送信がサーバー側を置き換えます。書いたものが写しなしに消えることはなく、Hyla はもう一方をどこに置いたか告げます。

## コマンドライン

```sh
hyla sync                    # 今すぐ同期（起動時と同じ）
hyla sync status             # どこへ、どこまで進んだか
hyla sync push               # サーバーの中身に関わらずこのマシンのを送る
hyla sync pull               # このマシンの中身に関わらずサーバーのを取る
hyla sync set backend webdav # webdav.url、webdav.user、webdav.password も
hyla sync set passphrase "…" # どのマシンでも同じもの
hyla sync set auto on
```

`hyla sync set` が取るのは `backend`（`webdav`、`s3`、`github`、`off`）、`passphrase`、`auto`、`webdav.url|user|password`、`s3.endpoint|bucket|prefix|region|accessKey|secretKey`、`github.repo|path|branch|token` です。
